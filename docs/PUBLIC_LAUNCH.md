## Why the Vercel build failed

GitHub pushes trigger Vercel builds. The app compilation succeeded; the postbuild verifier failed because a real retrieval function's `.nft.json` deployment manifest omitted `lib/context/chunks.jsonl.gz`. The file exists in the repository, but dynamic filesystem access is not consistently captured by Next tracing. The earlier route-specific verifier correction did not fix this packaging omission.

Postbuild now explicitly pins all six existing approved corpus artifacts into each of the 15 retrieval functions, then runs the independent corpus/privacy/size verifier. Prebuild still verifies the committed artifact hashes. Missing data/functions and oversized/private bundles still fail. Static and framework error pages do not require the corpus. Regression tests cover Vercel-style omitted references, idempotence, missing actual files and private artifacts. This repairs packaging without suppressing necessary checks.

The npm `cache-dir` warning is separate from the failure. Postbuild now invokes both scripts directly, avoiding the nested npm call. Vercel/platform-injected npm settings may still emit a warning elsewhere. Node is pinned to 22.x to match CI instead of accepting Node 26 implicitly.

## Enable AI only after a separate student rollout review

- **Provider permission:** Gemini API's [current terms](https://aistudio.google.com/docs/terms#age-requirements) prohibit under-18-directed clients. Production student generation, query helpers and the Gemini-only image solver exclude it even if configured. A paid API key does not remove the age restriction. No replacement provider has been certified for these students by local tests. Review permitted ages/regions, retention, training, subprocessors, deletion and required arrangements/consents with the selected provider before sending children's data. Self-hosted inference avoids an external answer provider but still needs a separately implemented, evaluated safety and operating setup.
- **Explicit destinations:** set `AI_PUBLIC_PROVIDERS` only to reviewed IDs (`groq`, `mistral`, `nvidia`, `cerebras`), configure only their keys, then set `AI_PUBLIC_ENABLED=1`. The allowlist covers automatic generation fallbacks, query helpers, hosted NVIDIA embeddings/reranking and Groq self-verification. Empty allowlist prevents production activation. Production Redis protection is mandatory and fails closed. Set `AI_PUBLIC_ENABLED=0` and redeploy to pause requests; auxiliary hosted AI also stops.
- **Student privacy:** publish a working operator contact and accurate privacy terms. Children should leave out names, school/roll numbers, phone/address details and faces. Text/notes/learning summaries selected by a tool can reach the approved provider; retrieval receives only a bounded question and curriculum scope. Existing image re-encoding strips EXIF, not private pixels. Do not advertise universal privacy/safety guarantees.
- **Accuracy and coverage:** teacher-review representative answers, harmful/injected prompts, multilingual requests, bogus citations, calculations and unsupported chapters. The recorded small lexical benchmark is 24/25; 43 chapters need coverage review, 26 lack mapped textbook chunks, `c10-eng-6` has no source and `c12-eng-1` fails its retrieval case. Follow `INDEXING_PLAN.md`; embedding the same bad/missing evidence again will not fix it. Limit any pilot to reviewed, covered chapters. Automated grounding is not teacher/factual verification.
- **Live acceptance:** test the chosen provider/account, quotas, shared budget/outages, latency/load, operator authentication and failure messages in a preview. The Gemini-only image solver requires an eligible replacement integration before student use. Local tests do not validate external account terms, deployment behavior or every generated answer.
