## Verification and limits

The report records 25,628 chunks (21,325 papers and 4,303 textbooks), 35,867 BM25 documents and 25,628 consistent MiniLM vectors. No malformed chunks, duplicate IDs, missing indexed chunks or missing/invalid/orphan vectors were found. 12,454 chunks have direct chapter mappings; 13,174 remain unmapped. There are no emitted OCR-specific chunks.

The benchmark passes 24/25 cases: 100% chapter hit rate, 89% top-three term recall, 94% overall term recall, MRR 1 and precision@3 1. The remaining failing case is `c12-eng-1`. These are curated term-overlap metrics, not teacher judgments. An incorrect economics chapter/query pair was corrected, so these final figures are not an identical-seed before/after comparison. Corpus, questions and retrieval code hashes prevent stale results from appearing current.

Strict TypeScript/lint, 81 JavaScript tests and five Python textbook identity cases pass. Tests cover malicious inputs on all 14 handlers before retrieval/providers, shared-provider payload framing with mocked transport, missing/poisoned evidence, fabricated citations, schemas, streamed limits, privacy, proxy attribution, optional database contracts and production-budget failure. Production build passes; all 23 API traces contain required artifacts and fit the 240 MB guardrail (largest approximately 199 MB). Local HTTP checks verify health 200, unauthenticated developer access 401, cross-site mutation 403, operator login 200 and chapter retrieval 200 with six excerpts. Browser checks cover mobile navigation, theme contrast, developer tool/coverage panels and full source inspection.

Local E5 q8 inference produced 384-dimensional vectors and ranked a relevant acids passage above an unrelated biology passage (cosine 0.891 versus 0.752). This is a smoke test, not a full re-embedding/model ranking. Live Gemini, Groq, NVIDIA and Mistral catalogs listed configured default chat IDs; listings do not verify quota, billing or generation quality.

- 43 chapters require source/coverage review. Lexical coverage, confidence and citations cannot prove factual correctness or correct calculations. Teacher review and larger multilingual/OCR/diagram benchmarks remain necessary.
- Full vectors remain MiniLM. A full E5 rebuild has not run. The optional classifier model has not been installed/evaluated. The experimental database backend was later removed; use the current deployment runbook.
- Every provider/tool pair has not been exercised against live generation APIs. Quota/billing/retention settings, target Redis outage behavior and deployment memory/latency need integration checks. Hosted free tiers have limits.
- Models receive no autonomous browsing, code execution or account tools, but pattern filtering/classifiers cannot guarantee harmlessness against every novel attack.
- Docker build/health could not run because the daemon is unavailable. React 18 builds, with Next warning of removal in the next major release.
- No deployment, storage upload, database mutation or credential rotation occurred. An empty npm audit does not certify optional Python packages or the entire application.
